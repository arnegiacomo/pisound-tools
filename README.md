# pisound-tools

Collection of tools for a Raspberry Pi with a [Pisound](https://blokas.io/pisound/) HAT running [Patchbox OS](https://blokas.io/patchbox-os/), written for my own setup and kept here in case they are useful to someone else 🤷‍♂️.

Each tool is its own directory with its own installer and README. Nothing depends on anything else here, so use whatever is needed.

| Tool | What it does |
| --- | --- |
| [`usb-audio-bridge`](usb-audio-bridge/) | Makes the Pi a USB audio device, so a computer's audio comes out of the Pisound alongside whatever Patchbox is running |
| [`modep-plugins`](modep-plugins/) | Gives MODEP the LV2 plugins Debian ships |
(more to come)

These are not officially supported Patchbox setups.
